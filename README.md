# 🔬 AI Research Assistant: RAG-based Scientific Literature Analysis

[![CI](https://github.com/Earwigmoth10/AI-Research-Assistant-RAG-based-Scientific-Literature-Analysis/actions/workflows/ci.yml/badge.svg)](https://github.com/Earwigmoth10/AI-Research-Assistant-RAG-based-Scientific-Literature-Analysis/actions)
![Python](https://img.shields.io/badge/python-3.9%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

Ask questions about a folder of research papers and get **grounded answers with citations** (file + page).
The assistant uses **Retrieval-Augmented Generation (RAG)** with **hybrid retrieval** (BM25 + semantic
similarity, fused with Reciprocal Rank Fusion), a built-in **retrieval evaluation harness**, a **CLI**
and a **Streamlit web app**.

It runs fully **offline out of the box** (no API keys, no model downloads) and upgrades to
sentence-transformer embeddings and an LLM (Anthropic Claude or OpenAI) when you want higher quality.

## ✨ Features

| Feature | Details |
|---|---|
| Multi-format ingestion | PDF (page-aware), `.txt`, `.md`; files or whole folders |
| Smart chunking | Sentence-aligned, overlapping chunks that keep `source` + `page` provenance |
| Hybrid retrieval | BM25 + dense/TF-IDF similarity merged by Reciprocal Rank Fusion |
| Pluggable embeddings | `tfidf` (offline default) or `sentence-transformers` |
| Pluggable generators | `extractive` (offline), `anthropic`, `openai` |
| Citations | Every answer lists numbered sources `[1] paper.pdf (page 4)` |
| Evaluation | Hit@k, Recall@k and MRR on your own labelled questions |
| Persistent index | Saved to disk; re-ingesting the same paper is a no-op |
| Interfaces | Python API, CLI (`rag-assistant`), Streamlit UI, Docker |

## 🚀 Quickstart

```bash
git clone https://github.com/Earwigmoth10/AI-Research-Assistant-RAG-based-Scientific-Literature-Analysis.git
cd AI-Research-Assistant-RAG-based-Scientific-Literature-Analysis

python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -e ".[ui]"

# Index the bundled sample papers and ask something
rag-assistant ingest data/sample_papers
rag-assistant ask "Why do random window-level splits inflate accuracy?"
```

Example (generated by running the pipeline on the sample papers):

![CLI demo](docs/images/cli_demo.png)

Plain-text version of the same kind of output:

```
Most relevant evidence from the indexed papers: To measure speaker independence, evaluation uses
speaker-disjoint splits so that no speaker appears in both training and test data. [1] Random
window-level splits leak speaker identity and report inflated accuracy. [1]

Sources:
  [1] cnn_stuttering_detection.txt (page 1) - relevance 0.0328
```

### Use your own papers

```bash
rag-assistant ingest path/to/your_pdfs/
rag-assistant ask "Which datasets were used and what were the main limitations?"
rag-assistant search "attention mechanism" -k 5          # retrieval only, no generation
rag-assistant stats
```

### Web app

```bash
streamlit run app.py
```

Upload PDFs in the sidebar, pick the retrieval mode, and chat with your papers.

### Better quality (optional)

```bash
pip install -e ".[dense]"        # semantic embeddings
pip install -e ".[anthropic]"    # or ".[openai]"

export ANTHROPIC_API_KEY=...     # see .env.example for all options
rag-assistant --embedder sentence-transformers --llm anthropic ingest data/sample_papers
rag-assistant --embedder sentence-transformers --llm anthropic ask "Summarise the main idea of hybrid retrieval."
```

With the `sentence-transformers` embedder, re-run `ingest` on a fresh `--index-dir` (or delete `index/`)
when switching from `tfidf`, because the two use different vector spaces.

### Python API

```python
from rag_assistant import ResearchAssistant

bot = ResearchAssistant()
bot.ingest(["papers/"])
answer = bot.ask("What evaluation metrics do the papers report?", top_k=5)
print(answer.format())
```

## 📏 Evaluation

Label a few questions with the source file(s) that should answer them
(see [`data/eval/sample_eval.json`](data/eval/sample_eval.json)), then run:

```bash
rag-assistant eval data/eval/sample_eval.json -k 3
```

```
Questions evaluated : 6
Hit@3              : 1.000
Recall@3           : 1.000
MRR                : 1.000
```

> ⚠️ This result is on the tiny bundled sample (3 short documents), so it only proves the pipeline is wired
> correctly. Build a labelled set from your own papers to get meaningful numbers, and compare
> `--mode bm25`, `--mode dense` and `--mode hybrid` on it.

## ⚙️ Configuration

All options can be set via environment variables (or a `.env` file):

| Variable | Default | Meaning |
|---|---|---|
| `RAG_EMBEDDER` | `tfidf` | `tfidf` or `sentence-transformers` |
| `RAG_LLM_BACKEND` | `extractive` | `extractive`, `anthropic`, `openai` |
| `RAG_CHUNK_SIZE` / `RAG_CHUNK_OVERLAP` | `180` / `40` | Chunk size and overlap, in words |
| `RAG_TOP_K` | `5` | Passages passed to the generator |
| `RAG_INDEX_DIR` | `index` | Where the index is stored |
| `ANTHROPIC_MODEL` | `claude-sonnet-5-5` | Model used by the Anthropic back-end |
| `OPENAI_MODEL` | `gpt-4o-mini` | Model used by the OpenAI back-end |

## 🧭 Limitations and roadmap

- The offline `extractive` generator quotes relevant sentences; it does not paraphrase or reason across passages. Use an LLM back-end for synthesis.
- Scanned PDFs need OCR before ingestion; tables and equations are extracted as plain text.
- Planned: cross-encoder re-ranking, FAISS for large corpora, answer-faithfulness evaluation, citation-graph exploration.
